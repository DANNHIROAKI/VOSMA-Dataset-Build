# 真实数据集的构建与使用说明

本实验采用 DocLayNet、MOT20 和 COCO 2017 ↔ Sama-COCO 三组真实数据，分别代表文档重复标注、人工标注与检测结果对照、对象标注版本对照。三组数据分别在 Hugging Face 发布，但采用一致的输入形态：**两侧矩形关系 $R_1,R_2$、语义分组信息，以及必要的来源与版本说明**。

本文规定构建与使用口径，不表示数据已经完成构建或上传。发布时应补充实际统计、下载地址和固定版本标识。这里的“构建完成”指原始标注已经完成配对、筛选和几何准备；**不包含 VOSMA 的算法索引或预计算采样结构**，算法自身的预处理仍计入实验成本。

三组主版本均采用单位记录权，使 VOSMA-Area 与 VOSMA-IoU 使用完全相同的输入，只改变采样权重。记 $I(r,s)$ 为交集面积，$A_r,A_s$ 为两个矩形的面积，则

$$
w_{\mathrm{Area}}(r,s)=I(r,s),\qquad
w_{\mathrm{IoU}}(r,s)=\frac{I(r,s)}{A_r+A_s-I(r,s)}.
$$

总质量为正时，两种算法分别按对应权重进行独立同分布、有放回采样。样本是**矩形记录对**，不是预先确认的一对一对象匹配。零交叠关系没有采样概率，因此这些实验属于加权候选关系核验，而不是全面的漏标、误检或异常发现。

## 1. DocLayNet：文档版面重复人工标注

### 1.1 数据集简要介绍

DocLayNet 是文档版面分析数据集，包含 80,863 个页面，覆盖金融报告、科学论文、法律法规、政府招标文件、手册和专利等领域。其 11 个版面类别包括正文、标题、表格、图片、列表和页眉页脚等，标注对象是页面中的矩形版面区域。[^doclaynet]

本实验不使用全部页面，而使用保留重复人工标注的部分。原论文报告 7,059 个双标页面和 1,591 个三标页面，共 8,650 个物理页面。不同标注可能在边界、类别或分块方式上存在差异，例如将一组子图标成整体或拆成多个区域。这些数字仅作为源数据规模参考，实际可用页面与框数以构建结果为准。[^doclaynet]

### 1.2 研究中的使用方式与实际意义

**实验单位是同一物理页面。** 主版本取 `precedence=0` 的有效版面框作为 $R_1$，取 `precedence=1` 的有效版面框作为 $R_2$。三标页面在主版本中也只贡献这一组标注对；另外两种标注组合仅作为独立的补充版本。

主版本不限制两侧类别相同。区域被标成不同类别本身就是值得核验的关系，不能在输入阶段将其删除。`precedence` 表示标注次序，用于区分标注层，不作为跨页面固定的标注员身份使用。[^doclaynet]

**VOSMA-Area 的意义：页面空间占比导向的核验。** 共同占据较大页面区域的框对获得更多抽样机会，可用于检查大范围版面区域的类别解释和分块关系。这里的面积是渲染页面坐标下的矩形交叠面积，不是原始纸张的物理面积，也不是文字内容的重要性。

**VOSMA-IoU 的意义：区域几何一致性导向的核验。** 相对重合度较高的框对获得更多抽样机会，可用于核验位置、尺度和分块方式接近的候选对应。它偏向几何相似关系，而不是专门优先寻找边界差异最大的区域。

这组数据的应用优势在于：版面区域本身就是任务对象，按绝对页面空间或相对区域重合度组织审查，都具有直接的解释。

### 1.3 构建的基本方法与流程

整体流程为：**保留原始重复标注 → 核对物理页面 → 分离两套标注 → 统一几何表示 → 隔离不同页面 → 核验并发布**。

页面身份结合文档类别、来源集合、文档名和页号确认，同时核对图像身份与尺寸。按照原始标注记录的 `precedence` 分层，不仅依赖图像级标记；不能用只剩单层标注或融合结果的版本代替原始重复标注。坐标统一对应官方页面 PNG，不混用 PDF 坐标。[^doclaynet]

**三组数据共用以下几何处理约定。** 从源图像像素坐标计算矩形端点，采用公共尺度 $Q=1000$，将端点乘以 $Q$ 后按最近整数舍入，恰好居中时取偶数，得到半开矩形 $[x_0,x_1)\times[y_0,y_1)$。先求原始右下端点再舍入，不分别舍入宽高后相加；不对各图像单独归一化或缩放。

仅排除非有限坐标、非正宽高及量化后退化的框，并记录数量。默认不裁剪出界框，合法负坐标也予以保留。保留来源记录不同但几何相同的矩形，不额外做匹配、几何去重、NMS 或按 IoU 阈值筛选，也不因某个框没有交叠对象就提前删除它。精确采样的对象是**发布后的定点矩形**，并不表示原始小数坐标的转换无损。

为形成一个可直接输入二维算法的实例，将每页两侧框共同平移到彼此分离的平面区域。区域间距依据实际框范围确定，使组内交集面积与 IoU 保持不变，跨页交集为零。这是语义分组的几何编码，不是重新生成或扰动真实框。

发布前核对重复页数、两侧有效框数、无效与空侧记录，并抽查页面叠框和组内交叠关系。所有筛选与配对失败均留有统计，不用全数据集规模替代重复标注子集规模。

### 1.4 构建后数据集的形态与使用

Hugging Face 上的主版本是**已经完成上述处理的双关系矩形数据集**。每个语义分组对应一个物理页面，包含两侧矩形、记录身份以及回溯页面和标注层所需的信息。运行输入提供统一的整数端点与单位权重，辅助信息保留原始分组、局部坐标及平移关系。

三组统一发布可直接加载的 NumPy 矩形数组和少量可追溯元数据，使用相同的列含义与分组约定。运行不依赖下载原始页面图像；发布内容不包含预先枚举的相交框对、对象匹配或算法索引。

使用时固定发布版本，直接加载 $R_1,R_2$，交给两种算法各自执行预处理与采样，无须再次处理原始标注。既可选取完整页面开展小规模验证，也可将所有已隔离页面作为一个全量实例；**每页等量采样后合并，不等于全局按质量采样**。空侧或零总质量实例保留其状态，用于边界情况检查，不伪造有效样本。

原始来源、许可、构建规则、版本与校验信息随数据保留。运行时仍须检查面积及累计质量等中间量的数值范围，不能仅凭整数坐标可存储就认定所有计算均不会溢出。

## 2. MOT20：行人 GT 与官方检测结果

### 2.1 数据集简要介绍

MOT20 是面向拥挤场景的多目标行人跟踪基准，共有八个序列。本实验使用公开人工标注的四个训练序列，共 8,931 帧，以及官方提供的 Faster R-CNN 检测结果，不使用缺少公开 GT 的测试部分。[^mot20]

原始任务研究行人的检测与跨帧跟踪；本实验只使用同帧的两套矩形框，不研究轨迹关联。拥挤画面使同一帧中可能存在较丰富的框交叠关系，但实际连接规模仍须统计，不能仅凭“拥挤场景”推定。

### 2.2 研究中的使用方式与实际意义

**实验单位是“序列名＋帧号”。** $R_1$ 保留有效标志为 `1`、类别为 `Pedestrian`（类别 ID 为 `1`）的人工 GT 框；$R_2$ 保留官方检测结果中几何有效且分数有限的框。[^mot20]

主版本采用“保留全部符合上述条件的官方检测”这一固定口径，不额外设置置信度阈值，不按可见度删除 GT，也不将检测置信度作为 Area 的记录权。两侧权重均为单位权，保证 Area 与 IoU 的输入一致。

**VOSMA-Area 的意义：绝对空间交叠导向的候选审查。** 人工框与检测框交集越大，候选关系获得的抽样机会越多，适用于按图像空间交叠贡献分配核验预算。它天然偏向较大共同矩形范围，不等于检测准确率或去重后的行人覆盖面积。

**VOSMA-IoU 的意义：相对定位一致性导向的候选审查。** 相对重合度较高的 GT—检测框关系更容易被抽到，可用于核验位置与尺度较一致的候选对应。但拥挤场景中不同人的框也可能相交，因此样本不能直接视为同一行人的匹配。

MOT20 在本研究中还承担拥挤关系下的性能实验。官方检测器使用过这些训练序列，因此结果用于评价采样算法，而不是证明检测器的独立测试泛化能力。[^mot20]

### 2.3 构建的基本方法与流程

整体流程为：**固定官方训练数据与检测输出 → 按序列和帧配对 → 筛选两侧记录 → 统一几何表示 → 隔离不同帧 → 核验并发布**。

首先依据序列信息确认帧范围和图像尺寸，然后在同一帧内分别整理 GT 与检测框。GT 轨迹 ID 仅用于回溯人工记录，不作为跨侧对象对应依据；检测记录采用能够区分原始记录的独立身份，不依赖可能重复的检测 ID。不同帧不能因坐标相近而发生连接。

几何处理沿用第 1.3 节的统一约定：$Q=1000$、半开整数矩形、默认不裁剪、不额外去重或 NMS、不按框间 IoU 筛选。检测分数保留为元数据，不预设它一定是统一的 $0$–$1$ 概率。需要置信度阈值实验时，另建明确命名的版本，不覆盖主版本。

对每帧的两侧矩形施加相同平移，依据实际框范围隔离不同帧，保留组内 Area 与 IoU。发布前核对序列与帧数、有效 GT 和检测框数、筛选数量、分数范围以及空侧情况，并检查分组隔离与局部交叠关系。

### 2.4 构建后数据集的形态与使用

发布形态与 DocLayNet 一致：**可直接加载的 $R_1,R_2$、分组信息和必要来源元数据**。区别在于，一个语义分组表示某个序列中的一帧，左侧是有效行人 GT，右侧是官方检测框。

发布版本已经完成 GT—检测数据的整理与坐标处理。下载后不需要重新运行检测器、不需要重新解析原始视频标注，也不需要下载视频帧才能执行几何实验；只需固定版本并加载两侧关系。

可以选取完整帧构造规模实验，或直接使用全量训练帧实例。两侧必须使用相同的帧集合；若需要嵌套规模版本，应按固定场景顺序逐帧加入，不独立抽取左右框，也不复制矩形扩大规模。轨迹和分数信息只承担来源追溯或明确声明的分层分析用途，不改变主版本的连接语义。

该数据的发布说明须保留官方来源、原始许可与派生处理规则，并区分“输入已经构建”和“采样算法已经预处理”。性能比较中的枚举基线也应利用同帧分组，不能故意枚举跨帧无意义的组合。

## 3. COCO：COCO 2017 与 Sama-COCO 标注对照

### 3.1 数据集简要介绍

COCO 是通用对象检测与实例分割数据集。Sama-COCO 使用 COCO 2017 图像，提供重新整理的对象框和分割标注。两者使用相同的训练与验证图像划分，分别包含 118,287 张和 5,000 张图像，实际对象类别为 80 类。[^coco]

Sama 的标注过程以预载的 COCO 标注为基础，允许修改、保留、删除和补充记录，其变化涉及轮廓精细化、crowd 拆分与小对象处理。因此，这组数据属于**标注版本或标注方案对照**，不描述为完全独立的重复人工标注。[^sama]

本实验只关注矩形框，不使用分割轮廓作为采样对象。共同图像数量与原始标注总量只是源数据背景，最终规模以身份核验、非 crowd 筛选和几何检查后的结果为准。

### 3.2 研究中的使用方式与实际意义

**实验单位是“共同图像身份＋统一类别”。** $R_1$ 使用 COCO 2017 的非 crowd 有效实例框，$R_2$ 使用 Sama-COCO 中同图像、同类别的非 crowd 有效实例框。主版本两侧均排除 `iscrowd=1` 的记录。

**VOSMA-Area 的意义：共同矩形范围导向的版本核验。** 交集面积较大的跨版本框对获得更多抽样机会，用于核验较大共同图像范围内的候选对象关系。这里研究的是矩形交叠，不是对象真实像素范围或分割轮廓的共同覆盖。

**VOSMA-IoU 的意义：对象框相对几何一致性导向的版本核验。** 高 IoU 框对更容易被抽到，可用于检查对象位置和尺度相近的跨版本候选对应。不同版本的 annotation ID 不构成真实对应关系，采样也不代替实例匹配。

同类别、非 crowd 的限定使几何比较更明确，但也排除了跨类别分歧，并不能完整覆盖 crowd 拆分带来的变化。标注规则不同也可能产生版本差异，因此不能把几何不一致一律解释为标注错误。轮廓明显变化而外接框变化很小的情况，同样不在本实验的轮廓评价范围内。[^sama]

### 3.3 构建的基本方法与流程

整体流程为：**固定两套原始标注 → 核验共同图像与类别 → 筛选非 crowd 框 → 统一几何表示 → 按图像及类别隔离 → 核验并发布**。

先依据可核验的图像身份建立两侧对照，检查文件身份和图像尺寸，再建立明确的类别映射。不默认双方 image ID、annotation ID 或类别数组位置相同。图像缺失、身份冲突和图像存在但没有有效框，应分别记录，不能混作同一种情况。

两侧独立排除 crowd 和无效几何，随后按照统一类别建立分组。共同图像中某个类别只在一侧保留框时，也记录相应空侧状态，不把两侧共有对象假装成已经匹配的实例集合。

矩形面积由最终端点计算，不直接使用可能表示分割面积的原始 `area` 字段。其余几何处理沿用第 1.3 节约定：$Q=1000$、半开整数矩形、不裁剪、不做匹配或交叠阈值筛选。每个“图像＋类别”组的两侧共同平移；同图像的不同类别也应隔离，以保证算法不会产生主版本不允许的跨类别连接。

发布前核对共同图像数、类别映射、非 crowd 框数、无效与空侧情况，并统计或抽查 bbox 变化、交集面积和 IoU 分布。需要确认最终矩形任务具有怎样的变化与交叠结构，不能仅凭分割标注总量增加就推定 bbox 实验更丰富。

### 3.4 构建后数据集的形态与使用

发布形态与前两组一致：**两侧运行矩形、语义分组与来源元数据**。一个分组对应同一图像中的同一类别，元数据保留原图身份、统一类别及两套标注的原始记录身份，但不保存未经确认的一对一匹配。

Hugging Face 上的版本已经完成跨来源配对、非 crowd 筛选、整数化及分组平移。下载后不需要重新处理分割轮廓或原始标注，也不依赖原图才能运行 VOSMA；直接使用同一对 $R_1,R_2$ 比较 Area 和 IoU 即可。

全量实验使用所有已隔离的图像类别组。按图像选择规模子集时，同一图像下的全部类别组一起选入，避免只挑交叠较多的类别或独立抽取两侧框。数据说明应明确其范围是“同类别、非 crowd 的框级对照”，不将结果扩展解释为全部 COCO—Sama 标注变化或分割质量评价。

与前两组一样，发布时保留来源、许可、构建规则、实际规模和固定版本标识。三套数据虽来自不同领域，但实验入口均为**加载固定版本的双关系矩形输入，再运行算法自身的预处理与采样**。
